## 较大幅度耦合轨迹

[coupled_large.json](../../artifacts/deployment_suite/coupled_large.json) 的起点仍是
`[0, -3.48, -1.23, -0.05, 0.42, 0.14]`，目标为
`[0.5, -3.48, -0.93, 0.10, 0.34, 0.14]`，均为测试数据。

| 指标 | 结果 |
|---|---|
| 最大请求单轴位移 | 0.5 rad，约 28.65° |
| 轨迹 | 121 点，dt=0.025 s，总时长 3 s |
| 最大终点关节误差 | 6.68e−8 rad |
| 峰值速度 / 加速度 | 0.26864 rad/s / 0.59915 rad/s²，仅对离线参数有效 |
| CPU 加密碰撞检查 | 181 个姿态，最大关节步进 0.005 rad |
| 最小球间隙 | 5.48856e−5 m，即约 0.055 mm，位于 base_link 与 link2 |
| 路径最小关节限位余量 | 约 0.119997 rad，使用离线位置界限 |
| 标准库读取 | 通过，无第三方包 |
| Mock 单调时钟执行 | 121 指令，完成且确认 Mock 停止；RMS=0 为理想模拟结果 |

较大位移并没有带来可用于真机的几何余量。现有球体碰撞模型可能包含保守包络造成的误判，
也不能代表安装夹具、线缆和实际误差；本轮没有放松球体或新增碰撞排除对来换取成功。
以上结果不能证明真实机械臂无碰撞，禁止直接用这些姿态进行真机试验。
